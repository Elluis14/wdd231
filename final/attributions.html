Attributions

This page lists sources, tools, and design inspiration used for the Radar Inmobiliario Juárez project.

Images & Media

  • Property and city images were created using image generation tools and exported as .webp files.
  • Hero and card images are illustrative and not tied to real listings.

Design & Layout

  • Color palette and typography inspired by modern data dashboards and accessibility guidelines.
  • Layout built with CSS Flexbox and Grid to support responsive behavior.

Project Context

  • Project built as a final assignment for the WDD 231 course.
  • If any external resource is added in the future (icons, libraries, or third-party text), it will be documented here.
